Adds your SanchiJawab AI chat assistant to every page of your site. Paste your Bot ID once, no code editing.

== Description ==

SanchiJawab learns from your own website and files and answers visitors' questions, with links to where the answer came from. This plugin puts it on every page of your WordPress site.

You need a SanchiJawab account and an assistant. In the dashboard, open your assistant and go to the Install tab to find the Bot ID and your service addresses.

== Installation ==

1. Plugins > Add New > Upload Plugin, choose the zip, Install, Activate.
2. Settings > SanchiJawab Chat: tick "Show the chat" and fill in Bot ID, API address and Widget address.
3. Visit your site; the chat bubble appears in the corner.

== Frequently Asked Questions ==

= Does it slow my site down? =
The chat script is loaded asynchronously (about 44 KB) and does not block the page.

= How do I hide it on some pages? =
Use "Hidden pages" in the Widget tab of your SanchiJawab dashboard; it applies on any website.
