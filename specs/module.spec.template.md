# Module spec template

Copy this file when a module's internal design needs to be agreed before coding (not every module needs one — see each `*-module-specs-index.md` for when this applies).

## Module

Name and which repo it lives in (`sanchijawab-backend` / `-admin` / `-widget`).

## Responsibility

What this module owns, in one or two sentences.

## Interfaces

Functions/endpoints/events it exposes, and to whom.

## Data owned

Tables or config it reads/writes.

## Dependencies

Other modules or third-party services it calls.

## Open questions

Anything not yet decided — remove this section once resolved.
